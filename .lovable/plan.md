

# Редизайн веб-дизайна Flamelix

Анимации уже на месте и работают хорошо. Проблема в самом визуальном дизайне: слабая цветовая палитра, однообразие секций, отсутствие визуальных акцентов и глубины. Вот что нужно исправить.

---

## Проблемы текущего дизайна

1. **Монотонная палитра** -- весь сайт выглядит "грязно-коричневым", нет контраста между primary и secondary цветами
2. **Карточки услуг** -- слишком бледные, почти сливаются с фоном, нет визуальной иерархии
3. **Bento-grid не работает** -- "Сквозная аналитика" (col-span-2) визуально не отличается от остальных карточек, пустое пространство
4. **Hero-секция** -- текст слабо читается на тёмном фоне, описание почти невидимо
5. **Секция процесса** -- список шагов выглядит как plain text, нет визуальных акцентов
6. **Команда** -- только инициалы вместо фото, карточки однообразные
7. **Отзыв** -- один отзыв на всю секцию, визуально пустая
8. **Контакт-форма** -- стеклянные инпуты почти невидимы на тёмном фоне
9. **Footer** -- простой и скучный, нет визуальной завершённости

---

## План улучшений

### 1. Обновление цветовой палитры
- Сделать primary ярче и насыщеннее (сдвинуть к более оранжево-золотому)
- Добавить accent цвет (тёплый индиго/синий) для вторичных акцентов
- Увеличить контраст тёмных секций -- сделать фон чернее, текст светлее
- Добавить subtle градиенты на заголовки (gradient-text)

### 2. Hero-секция
- Увеличить контраст текста: сделать заголовок ярко-белым, не серым
- Добавить subtle badge/pill над заголовком ("Маркетинг для девелоперов")
- Статистики внизу -- сделать числа крупнее с более ярким акцентом
- Улучшить CTA-кнопки: больше padding, более заметные

### 3. Секция услуг (Bento-grid fix)
- Заполнить пустое место в карточках col-span-2 -- добавить декоративные элементы или иллюстрации
- Увеличить контраст карточек: чуть более плотный фон, заметная тень
- Добавить цветовой акцент на иконки (gradient background вместо простого primary/10)
- Увеличить размер шрифта заголовков карточек

### 4. Секция процесса
- Добавить вертикальную линию-таймлайн слева, соединяющую шаги
- Активный/hover шаг подсвечивается градиентом
- Номера шагов -- крупнее, с акцентным кругом

### 5. Секция проектов
- MR Group кейс: увеличить изображение, сделать overlay ярче
- KPI -- добавить крупные числа вместо текстовых лейблов
- Другие кейсы -- добавить hover-эффект с подчеркиванием

### 6. Секция команды
- Увеличить карточки, добавить больше пространства
- Сделать аватары крупнее с более заметным gradient border
- Добавить подсветку роли (badge с цветом)

### 7. Секция отзывов
- Увеличить размер цитаты
- Добавить декоративные кавычки крупнее
- Добавить фоновый паттерн или текстуру

### 8. Контакт-форма
- Сделать инпуты более видимыми: увеличить контраст фона
- Добавить focus-состояния с ярким primary glow
- Увеличить отступы внутри формы

### 9. Header
- При скролле: добавить subtle shadow для глубины
- Увеличить размер логотипа

### 10. Footer
- Добавить градиентную линию-разделитель сверху
- Увеличить spacing, добавить декоративный элемент
