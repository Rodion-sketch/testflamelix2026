

# Редизайн Flamelix: обновление до стандартов 2026

## Что сейчас не так

Сайт выглядит устаревшим из-за нескольких факторов:
- Статичная, "плоская" подача контента без динамики
- Отсутствие микроанимаций и интерактивности при скролле
- Монотонная сетка без визуальных акцентов
- Нет фото команды (только инициалы)
- Одинаковый ритм секций — каждая выглядит как копия предыдущей
- Нет глубины: отсутствуют blur-эффекты, glassmorphism, градиенты

## Предлагаемые улучшения

### 1. Scroll-анимации (Intersection Observer)
Добавить появление элементов при скролле: карточки, заголовки, статистика плавно появляются снизу/сбоку при попадании в viewport. Сейчас анимация есть только у hero-секции.

**Компоненты**: Создать хук `useScrollReveal` и применить ко всем секциям.

### 2. Hero-секция: параллакс и видео-фон
- Добавить легкий параллакс-эффект на фоновое изображение при скролле
- Или заменить статичное фото на короткое зацикленное видео (опционально)
- Добавить floating-элементы (декоративные круги/градиенты) с CSS-анимацией

### 3. Bento-grid для секции услуг
Заменить однообразную 3x2 сетку на Bento Grid — модный формат 2024-2026:
- Главные услуги занимают двойные ячейки
- Разная высота карточек создает визуальный ритм
- Добавить hover-эффекты с gradient border и scale

### 4. Карточки команды: фото + стеклянный эффект
- Заменить инициалы на реальные фотографии (placeholder пока нет фото)
- Glassmorphism-стиль: полупрозрачный фон, backdrop-blur, тонкая граница
- Hover: легкий подъем карточки (translateY) + свечение

### 5. Горизонтальный скролл для кейсов
Вместо вертикального списка — горизонтальная лента с карточками проектов:
- Snap-scroll на мобильных
- Крупные изображения кейсов
- Hover-раскрытие деталей

### 6. Обновление типографики и отступов
- Более крупные и смелые заголовки с gradient-text для акцентных слов
- Увеличить whitespace между секциями
- Добавить декоративные линии/разделители между блоками

### 7. Интерактивный FAQ
Заменить стандартный FAQ на аккордеон с плавной анимацией, иконками и подсветкой активного пункта.

### 8. Floating CTA-кнопка
Фиксированная кнопка "Связаться" в правом нижнем углу, которая появляется после скролла hero-секции.

### 9. Cursor-follower эффект (десктоп)
Тонкий световой блик, следующий за курсором — особенно заметен на тёмных секциях. Создает ощущение живого интерфейса.

### 10. Gradient borders и glow-эффекты
Заменить обычные `border-border` на анимированные gradient-бордеры при hover. Добавить мягкое свечение (box-shadow с цветом primary) на ключевые элементы.
